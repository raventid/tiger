# Preface

Welcome to Modern Compiler implementation book companion guide. The material is structured in the same way as original book with a goal to elaborate on a complex ideas presented in original book and modernise source code by substituting SML with Ocaml language.

This book will also share extra reference to useful visualisation and materials from other books that will help you to navigate original text with more confidence.


There is no best way to use this book, it all depends on your needs. You can only refer to idiomatic Ocaml implementation of compiler here or you can also read our attempt to elaborate on theory presented in the original book. The final goal is to help self-learners to read original university text book from beginning to the end and be comfortable with all the material presented there.

As we are repeating the same structure as an original book we will keep the same structure in this companion guide.
