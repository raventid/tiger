# Preface

Welcome to the *Modern Compiler Implementation* book companion guide. The
material is structured in the same way as the original book, with the goal of
elaborating on the complex ideas presented there and modernising the source
code by substituting SML with OCaml.

This companion also shares extra references to useful visualisations and
materials from other books that will help you navigate the original text with
more confidence.

There is no single best way to use this book — it all depends on your needs.
You can refer only to the idiomatic OCaml implementation of the compiler, or
you can also read our attempt to elaborate on the theory presented in the
original book. The final goal is to help self-learners read the original
university textbook from beginning to end and become comfortable with all the
material presented there.

In the original preface you can find how the chapters depend on each other
(*"Course sequence — the figure shows how the chapters depend on each other."*).
Because we mirror the structure of the original book, this companion keeps the
same chapter ordering throughout.
